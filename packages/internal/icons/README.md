# `@hyperscal/icons`

A collection of icons

## Usage

```tsx
import { Icon } from '@hyperscal/icons'

<Icon name='user' />
```

## Workflow

1. Find the Icons you want to use at [iconify site](https://icon-sets.iconify.design/tabler/)
2. Uncomment icon at [icons.mjs](./icon.mjs)
3. Run command `gen` to generate new CSS icons file

## Available Scripts

In this package, you can run:

- `pnpm run gen`: Generate CSS icons and icons types
- `pnpm run build`: Build package
