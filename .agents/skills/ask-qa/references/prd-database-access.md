# Terminal PRD database access

PRDs use the same PostgreSQL store as Q-Rex. For a known menu, first read its exact virtual identifier without an identity: the CLI returns its active PRD only when exactly one identity has an active document for that module and menu. It reports missing or ambiguous matches without listing owners or other documents. If ambiguous, establish the intended browser identity and set `AUTOMATION_PRD_IDENTITY` to its `automation-dummy-user-id` from local storage. An explicitly configured identity always takes precedence. This identifier partitions local preview data; it is not authentication. Configure `AUTOMATION_DATABASE_URL` as for the API. If access is unavailable, report the blocker instead of creating a repository PRD.

From the repository root, `node server/modules/agent/prd-cli.mjs read docs/prd/<module>/<menu>.md` reads one. `list` and `write` require the intended identity explicitly, even after a unique read. These paths are virtual identifiers. `write <identifier>` reads a JSON object from stdin with `content` and `expected` (the exact previously read content, or null if absent). It rejects stale changes. A draft must preserve unchanged validations and leave new or changed items without `[validated]`.

Present the complete saved draft for explicit review. After the user accepts the exact proposed reviewed content, provide `approvedSha256` in the write JSON as the SHA-256 of that exact UTF-8 content. This value records the human decision in the agent workflow; calculating a hash, a create request, or silence is not approval. The write fails if approval is required and the digest does not match. Preserve the existing review gate and reviewer metadata. Do not write PRD contents to the repository.

If an update to a reviewed PRD would remove or change an existing validated line, the database requires approval before saving it even as a draft. Present the exact proposed content first, obtain the explicit scoped decision, then write with its digest; retain the existing document if the decision is absent or rejected.
