# E2E BDD troubleshooting

| Symptom                                             | Cause                                                                 | Fix                                                                                                                                                                                                                                                            |
| --------------------------------------------------- | --------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Step not found by playwright-bdd                    | Step text mismatch (spacing, casing, parameter format)                | Compare with the `.feature` line exactly. Use `{string}` for parameters. Run `pnpm test:bdd` after any `.feature` edit (it runs bddgen first)                                                                                                                  |
| New POM not available in steps                      | Not registered in `base.fixture.ts`                                   | Add it to `BddFixtures` and `test.extend<BddFixtures>({...})`                                                                                                                                                                                                  |
| MSW handler not intercepting                        | `@mock` tag missing, or `network.enable()` never ran                  | Add `@mock` to the scenario tag line                                                                                                                                                                                                                           |
| `network.use()` has no effect                       | Handler registered after the request already fired                    | Interaction mocks: register in `And` after the list-page `Given`. Navigation mocks: register before the `When` navigation                                                                                                                                      |
| Shared mock hits the wrong list API                 | `pageContext` not synced from scenario tags or URL                    | Call `syncPageContextFromScenario()` in the list-page `Given` step                                                                                                                                                                                             |
| `@smoke` scenario hitting MSW                       | `@mock` accidentally added                                            | Remove `@mock`. Smoke tests must reach the real backend                                                                                                                                                                                                        |
| `delay` import conflict                             | Name clash with an existing `delay` helper                            | `import { delay as mswDelay } from "msw"`                                                                                                                                                                                                                      |
| Exploration uses huge context or truncates mid-pass | Reading the full snapshot inline each step                            | Use `playwright-cli` with a named session. Search the saved snapshot for the section you need                                                                                                                                                                  |
| `@fixme` and `quarantine` used interchangeably      | Confusing a product bug with a flaky test                             | `@fixme` = real defect + `@ref:<JIRA-ID>`, skipped. `quarantine` = unreliable test; check runner-specific skip and failure behavior. BDD currently skips it unless `RUN_QUARANTINE=1`                                                                          |
| Data-dependent mutation fails on re-run             | Mutating seed data or a previous run's leftovers                      | Use verified E2E-owned records; if required E2E data cannot be found or provided, explain the limitation and ask permission to use non-E2E data for that specific scenario before seed mutation. Restore and verify wherever possible; without approval, skip. |
